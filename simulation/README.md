# Proteus Simulation

## Software

Proteus 8 Demonstration / Schematic Capture.

## Simulation Procedure

1. Open the project schematic in Proteus.
2. Start the simulation.
3. Apply a valid binary address combination.
4. Observe the decoder output/selected memory path.
5. Observe the D flip-flop storage/output indicators.
6. Change the address inputs.
7. Confirm that the selected memory section changes according to the decoder logic.
8. Record the observed outputs for the final project report.

## Verification

The most useful verification artifact is a table containing:

- Applied address
- Selected decoder output
- Data written, if applicable
- Data read/observed
- Output indicator state

The exact values should be filled from the actual Proteus simulation rather than inferred from the screenshot.
